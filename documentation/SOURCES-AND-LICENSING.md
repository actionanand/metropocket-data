# Sources and licensing

This repository separates tooling from source datasets.

For every production dataset:

- record authoritative source URLs/documents in `COVERAGE.md`,
- record the verification date,
- note whether timings/LCNs are official, manually verified, or community-sourced,
- verify redistribution rights before publishing derived data,
- do not include copyrighted logos or artwork unless clearly permitted.

Community data can help identify changes but should not silently override a stronger official source.
